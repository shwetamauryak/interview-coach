# 🎤 AI Interview Coach

An AI mock interviewer that asks one question at a time, follows up on vague answers, digs into your own projects, and finishes with a scorecard and model answers. Built for the **Build Your First AI App 2026** hackathon.

## The problem
Students and freshers fear interviews and rarely get realistic practice. Friends go easy on them, and generic chatbots just answer questions instead of interviewing.

## What it does
- Choose a company style (Amazon, Google, Microsoft, Indian IT services, startup, HR round), a role and a level.
- Paste your resume or project details; the interviewer asks specific questions about *your* work.
- Realistic flow: one question at a time, follow-ups when answers lack detail, no hints during the interview.
- At the end: overall score, five skill scores, strengths, improvements, per-question feedback with a stronger sample answer, and next steps.
- Works in English, Hindi or Hinglish.

## AI implementation
- An LLM (default: Llama 3.3 70B through Groq's free tier) accessed with the OpenAI-compatible Python client, so the provider can be swapped by changing `BASE_URL` and `MODEL`.
- **Prompt engineering, not model training:** a system prompt defines the interviewer's behaviour, and `company_styles.py` holds each company's public interview style.
- The scorecard is generated by a second prompt that returns structured JSON, which the app renders.

## Run locally
```bash
pip install -r requirements.txt
mkdir -p .streamlit
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # then put your free API key inside
streamlit run app.py
```
Get a free API key from Groq (console.groq.com) or Google AI Studio. For Google, set
`BASE_URL = "https://generativelanguage.googleapis.com/v1beta/openai/"` and a Gemini model name. Check each provider's current free limits.

## Deploy (free)
Push to GitHub (**never** commit `secrets.toml`), then deploy on Streamlit Community Cloud or Hugging Face Spaces and add `API_KEY`, `BASE_URL`, `MODEL` in the platform's Secrets settings.

## Limitations
- Company styles come from general public information, not insider knowledge.
- AI feedback is an estimate, not a hiring decision.
- Conversations are not stored.
